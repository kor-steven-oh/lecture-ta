# Claude Code 입문부터 에이전트 활용까지

대상: 터미널과 개발 도구를 처음 사용하는 비개발자·입문자.
형식: 독립 실행 HTML 슬라이드, 강사 노트, 출처, 복사 가능한 예제, 실습 파일.
교육 시간: 본 수업 360분 + 휴식 30분 권장. 빠른 과정은 1~5장과 종합 실습 중심.
공식 문서 확인일: 2026-11-02. 가격·모델명·기능 가용성은 수업 직전 재확인.

## 1. AI·LLM·에이전트 이해 (30분)
AI/ML/생성형 AI/LLM의 관계, 토큰, 학습과 추론, 컨텍스트, 환각, 검색과 RAG, 도구 사용, 워크플로와 에이전트, Claude와 Claude Code의 차이.
## 2. 터미널 기초와 설치 (45분)
터미널/셸/CLI, OS별 실행, 경로와 현재 폴더, 명령과 자연어 구별, 복사와 중단, 설치·로그인·사용량, 첫 프로젝트 열기, 오류 해결.
## 3. 첫 작업과 프롬프트 (45분)
읽기 전용 탐색, 목표/맥락/제약/산출물/검증, 파일 참조, 작은 수정, 계획 모드, 피드백, 실습 1: 가상 온보딩 자료 요약.
## 4. 검증·복구·보안 (40분)
에이전트의 작업 루프, 도구 호출과 권한, diff, 테스트와 수용 기준, Git, 체크포인트, 데이터 보호, 프롬프트 인젝션, 실습 2: HTML 안내문.
## 5. 컨텍스트와 프로젝트 지침 (35분)
컨텍스트 비용, 세션 재개와 요약, CLAUDE.md, 자동 메모리, 설정 범위, 모델 선택, 작업 인수인계.
## 6. Skills·MCP·Hooks (45분)
기능 선택 기준, 직접 실행하는 Skill, MCP 연결과 인증·권한, Hook 이벤트와 설정 예제, 플러그인, 실습 3: 재사용 워크플로.
## 7. 서브에이전트와 자동화 (50분)
역할과 도구 제한, 사용자 정의 서브에이전트, 위임 계약, 병렬 작업과 worktree, 실험적 Agent teams, 비대화형 CLI, Agent SDK, 비용·중단·평가.
## 8. 종합 실습과 운영 (70분)
가상 온보딩 키트 제작 40분, 동료 검토 10분, 퀴즈·해설 10분, 업무 도입 계획 10분. 실패 사례, 체크리스트, 용어집, 명령 치트시트와 공식 자료.

## 공통 교육 설계
- 실제 인사정보 대신 가상 회사 자료를 사용한다.
- 모든 명령은 입력 위치를 표시한다: OS 터미널 / Claude Code 내부 / 파일 내용.
- 개념 설명 → 강사 시연 → 따라 하기 → 완료 기준 확인 순서.
- 명령 암기보다 작업 범위, 검증 증거, 복구 경로를 스스로 설명하는 능력을 평가한다.
- 고급 설정은 별도 예제 디렉터리에 두고 이 프로젝트에 자동 활성화하지 않는다.
