# 선택 실습 예제

예제는 자동 활성화하지 않았습니다. 각 내용을 읽고 필요한 것만 배치하세요.

- `CLAUDE.md` → `workshop/CLAUDE.md`
- `skills/review-onboarding/SKILL.md` → `workshop/.claude/skills/review-onboarding/SKILL.md`
- `agents/evidence-reviewer.md` → `workshop/.claude/agents/evidence-reviewer.md`
- `hook-settings.json`의 `hooks` → `workshop/.claude/settings.json`의 기존 설정에 병합
- `team-settings.json`의 `env` → 선택 실험 환경의 설정에 병합

기존 설정 파일을 통째로 덮어쓰지 마세요. 서브에이전트·설정이 로드되지 않으면 새 세션에서 확인하세요. Hook은 단순 알림 예제이며 검증이나 차단을 하지 않습니다. Agent teams는 실험 기능으로 기본 수업에 필요하지 않습니다.
