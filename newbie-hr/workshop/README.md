# 실습 안내

이 폴더를 Claude Code의 작업 폴더로 여세요. 자료는 모두 가상입니다.

1. `materials/`를 읽기만 하도록 요청합니다.
2. `output/checklist.md`에 첫날 체크리스트를 작성합니다.
3. `output/welcome.html`을 만들고 브라우저에서 확인합니다.
4. `output/review.md`에 근거 대조와 동작 확인 결과를 기록합니다.
5. `output/handoff.md`에 결정·미확인 사항·다음 작업을 기록합니다.

시간과 장소 충돌은 교육을 위해 의도적으로 포함했습니다. 임의로 확정하지 말고 담당자 확인 항목으로 남기세요. 식대 금액은 제공하지 않았습니다.

고급 예제는 상위 `examples/`에 있습니다. 검토한 파일만 이 폴더의 적절한 위치로 복사하세요. 기본 실습에는 Git, MCP 연결, 플러그인, Agent teams가 필요하지 않습니다.
