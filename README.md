방향키로 이동하고, **O**로 목차, **N**으로 발표자 노트를 엽니다. **F**는 전체 화면, **P**는 인쇄/PDF 저장입니다. 모바일에서는 하단 버튼이나 좌우 스와이프를 사용합니다.

본문·노트·이미지는 오프라인에서 동작합니다. 외부 출처 열기에는 인터넷이 필요합니다. 노트는 현재 화면 위에 표시되므로 화면 공유 중에는 별도 강사 가이드를 사용하세요.

시각 자료 보강판: 주요 사례 20장에 사진·공개 이미지 21개, 기사·연구 카드 23개와 설명용 삽화를 반영했습니다. 이미지를 클릭하면 크게 볼 수 있습니다.
